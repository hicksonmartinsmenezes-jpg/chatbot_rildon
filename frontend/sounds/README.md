# Sons do painel

Coloque aqui os arquivos de som para alertas:

- `ticket.ogg` — tocado quando um novo ticket chega
- `message.ogg` — tocado quando uma nova mensagem chega

Formato recomendado: OGG Vorbis (melhor compatibilidade) ou MP3.

Se esses arquivos não existirem, o sistema usa a Web Audio API
como fallback (beep sintético).
